# 日文 50 音隨機出題練習系統

### 💡 專案靈感與動機

本專案開發於大學大二修讀日文選修期間。為了提升自己與同學背誦 50 音的效率，結合資工系所學，嘗試開發這款能分級隨機抽題的命令列練習工具。

### 🛠️ 目前功能

* **Level 1 (平假名模式):** 隨機抽出平假名，由使用者輸入羅馬拼音進行核對。
* **即時計分機制:** 系統會即時統計目前的答題正確率。

### 🚀 未來優化目標

1. 預計導入 Level 2（片假名混合模式）與 Level 3（漢字單詞讀音核對）。
2. 未來規劃結合前端網頁（HTML/CSS/JS）或是 Python 圖形介面（GUI），將系統視覺化。
3. 預計串接輕量化資料庫（SQLite），提供「錯題本」功能，針對使用者不熟的字型加強出題。
